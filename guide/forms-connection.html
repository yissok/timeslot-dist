Open Timeslot → Connection → Create database opens the step-by-step wizard. It chooses instructions for your device and lets you switch between Desktop and Phone or tablet.

Set up your Timeslot database

Desktop and phone use the same Setup worksheet. On desktop, use Google Sheets in your browser. On a phone or tablet, use the Google Sheets app for this one-time setup and a Private/Incognito browser session for the Google links (Safari Private on iPhone). After setup, Timeslot works in your browser with the spreadsheet closed.

Use disposable data. This proof makes the spreadsheet publicly readable and accepts unprotected Form commands. The Setup sheet explains this before you approve it. Use dummy booking names.

  1. Copy your database. Copy the sheet-db template and name the new copy Timeslot database. On a phone, open the template in Sheets and choose ⋯ → Share & export → Make a copy. Work in the new copy, not the original template.
  2. Open Setup. Select the Setup worksheet in the copy. Tick B2 — Prepare links. The temporary install link appears in B4. If there is no Setup worksheet, the template needs its connector update; the older desktop menu is described below.
  3. Authorize your script. Copy the link address from B3 — Authorize into a Private or Incognito browser window; on iPhone use Safari Private. Sign in to only the Google account owning this copy and approve the requested permissions. Keep this private session open for B4. B3 is required: do not skip it even if its final page is blank or reports denial after approval.
  4. Install the setup trigger. Copy the current B4 link address into the same Private or Incognito session. Wait for the browser to report Setup trigger installed. A temporary link can be regenerated by ticking B2 again; use the new B4 afterward. If it says Authorisation is required to perform that action, return to B3 and complete authorization with the copy-owner account before retrying.
  5. Approve and run setup. Return to the copied Sheet. Read the disclosure in B14, then tick B5 to accept it. Wait for B7 to say Public setup acknowledged for this copy. Tick B6 to finish., then tick B6 — Finish setup. Wait for B7 to report completion. If setup stops, read B8 and fix the stated issue before retrying; keep this copy so setup can reuse its resources.
  6. Return to Timeslot. Open B10 — Open Timeslot. The app imports this copy's connection and checks it. Confirm the displayed Sheet name and ID, then choose Use this Sheet. This separate confirmation creates Timeslot's settings, slots and bookings tables. If the return link cannot open your usual browser, copy the complete connection JSON from B9, open Timeslot there, and paste it into menu → Connect database.
  7. Create your schedule. Close the spreadsheet. In Timeslot, open Schedule, choose a date and timezone, and create the schedule. Book a free hour using a dummy name, refresh, and cancel it. Reload Timeslot to confirm the saved connection and schedule return.

The wizard remembers your selected device and current step on this browser. It cannot see which Google screens you completed: follow the confirmation shown at each step. A successful return-link import checks the connection; it does not create Timeslot tables until you choose Use this Sheet.

Existing desktop menu and connection JSON

An existing connector keeps sheet-db → Set up public Forms POC as a desktop shortcut to the same database initializer. Approve Google permissions and the public-access prompt; if consent interrupts setup, choose it again. Paste its generated JSON into Timeslot's menu, connect, check the name and ID, then choose Use this Sheet. The new Setup worksheet requires the current template connector.

If Google shows a denial or blank page

Keep the Google account isolated in a Private session. Record the page message and any error code. The earlier mobile proof completed its callback and authorized trigger despite a misleading authorization-link denial, so the final Sheet setup result matters. Do not treat a blank browser page as proof of successful installation. If B4 reports installation, return to the Sheet and continue; if it does not, stop and report the exact result. Do not post the complete temporary URL.

Disconnect and forget removes this browser's saved connection. A timed-out booking may have completed: keep the page open and use Retry the same change when offered. A new browser or device needs the same connection link or JSON once.

Form submissions and response history can retain values after current rows are deleted. A copied template may contain old dummy history. Its setup must create resources for the actual copy; never reuse the original template's connection details.
